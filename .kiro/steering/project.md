# To-Do List Life Dashboard

## Technical constraints
- HTML, CSS, and vanilla JavaScript only (no frameworks, no backend)
- Data stored in browser Local Storage
- Must work in modern browsers (Chrome, Firefox, Edge, Safari)
- Only 1 CSS file in `css/` and 1 JavaScript file in `js/`

## Features
- Greeting with current time and date, custom name
- 25-minute focus timer (Start, Stop, Reset, adjustable duration)
- To-do list: add, edit, complete, delete, prevent duplicates
- Quick links saved in Local Storage
- Light / Dark mode

## Challenges chosen
1. Light / Dark mode
2. Custom name in greeting
3. Prevent duplicate tasks (plus bonus: change Pomodoro time)
