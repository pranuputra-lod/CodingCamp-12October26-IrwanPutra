# To-Do List Life Dashboard

Dashboard produktivitas sederhana: jam & salam, focus timer, to-do list, dan quick links.
Dibuat dengan HTML, CSS, dan JavaScript murni. Data disimpan di Local Storage browser.

## Fitur
- Jam, tanggal, dan salam sesuai waktu (pagi / siang / sore / malam)
- Focus timer 25 menit (Start, Stop, Reset)
- To-do list: tambah, edit, tandai selesai, hapus
- Quick links yang bisa ditambah dan dihapus

## Tantangan yang dipilih
1. Mode terang / gelap
2. Nama custom di salam
3. Cegah tugas duplikat
4. (Bonus) Durasi timer bisa diubah

## Struktur folder
```

```

## Cara menjalankan
Buka `index.html` di browser. Tidak perlu instalasi apa pun.
